# Prompt log (AI-assisted development)

Tool: Claude (Sonnet 5.5) in an agentic coding session. Prompts are in the order they were sent.

1. **Brief.** Shared the take-home PDF and the reference URL, with no further instruction beyond "this is the reference".
   - Outcome: the assistant could not fetch the reference (the site blocks automated access) and asked for screenshots, photos and animation details instead of guessing.
2. **Reference material.** Uploaded full-page screenshots of the listing, 12 photo-tour screenshots (thumbnail strip, every room section) and the PDF again.
   - Outcome: plan locked in: React + Vite, plain CSS, data-driven page, three views (listing, photo tour, lightbox), desktop only.
3. **Build** (the assistant's own sequence from here):
   1. Scaffold project, `data.js` content manifest taken from the screenshots, placeholder photo generator.
   2. `useModal` hook (Esc, focus trap, focus restore, scroll lock), `Lightbox`, `PhotoTour`.
   3. Listing sections: header, hero grid, overview, sleeping, amenities, calendar, reviews, map, host, things to know, nearby.
   4. Styles split into tokens / base / listing / overlays.
   5. Browser verification with Playwright: open tour from "Show all photos", open lightbox, ←/→ and clamping, Tab trap, Esc layering, focus return.
   6. Fixes from verification: removed scroll-reveal that hid sections in full-page captures; replaced `inert` prop with a DOM attribute for React 18/19 compatibility.
   7. Architecture diagram generated from `scripts/gen-architecture.mjs` (SVG + PNG), then re-laid-out after visual review because arrows crossed text.
   8. Sub-agent and skill configs in `.claude/`.

Notes
- The photo files themselves were not available to the assistant; placeholders are generated by `npm run photos`.
- Anything marked "assumption" in the README was not visible in the supplied screenshots.
